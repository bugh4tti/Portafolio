### 🚀 Proyectos destacados

- **DayCosmetics** — Plugin de cosméticos para Minecraft: kill effects, tags, hats, gadgets y pets.
- **DayDrops** — Sistema de ítems exclusivos que dropean los jugadores al morir, ignorando el keepInventory.
- **DayEdit** — Editor de ítems vía comandos y GUI (lore, encantamientos, nombre).
- **DayKoths** — Gestión de Koths con menús, horarios (schedules) y recompensas.
- **DayStaffs** — Comandos de moderación para staff (freeze, vanish, etc.).
- **DayTrades** — Sistema de trade entre jugadores mediante menú de dos lados.
- **DayUtils** — Comandos utilitarios varios para el servidor.
- **DayWarps** — Sistema de creación y gestión de warps.
- **PlayerKits** — Configuración de menú de kits para servidor.
- **Rooms** — Plugin de salas privadas de práctica para servidores BoxPvP.
